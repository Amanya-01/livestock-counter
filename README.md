# Livestock Counter

This repository contains a livestock counting system based on a baseline and improved deep learning implementation.

## Project Overview

The goal of this project is to detect and count livestock in images or video using deep learning techniques. This repository is intended to serve as a starting point for:

- baseline model implementation
- improved model experimentation
- data handling and preprocessing
- evaluation and inference workflows
